# External / Quarantined Docs

本目录用于存放 **与当前仓库实现不一致** 的外部文档（例如：包含 `backend/`、`frontend/`、FastAPI/React/Playwright 等引用，但本仓库实际为 PyQt6 桌面应用，且不存在对应目录/代码）。

保留目的：
- 作为“外部灵感/历史调研”参考
- 避免误导当前仓库的开发与重构工作

规则：
- `docs/` 目录只保留与本仓库当前实现匹配、可执行验证的文档。
- 若未来决定引入对应后端/前端项目，应重新在新仓库或明确的子目录内落盘文档与代码，并更新 `docs/` 的说明与验收方式。
