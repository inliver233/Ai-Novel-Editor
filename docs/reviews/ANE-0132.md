# ANE-0132 — documentSaved 的唯一来源

## 结论
`Shared.documentSaved` 只在 `ProjectManager.update_document()` 的成功持久化路径中触发，符合“唯一来源”约束。

## 证据
- `src/core/project.py`：`update_document()` 成功保存后调用 `self._shared.documentSaved.emit(doc_id, doc.content)`（约 331-369 行区间）
- 代码库中不存在其它 `shared.documentSaved.emit(...)` 调用点
