# ANE-0025 — archive/experimental 处置决策

## 决策
本批次不做“迁移到单独分支/单独仓库”或“彻底移除”。选择 **保留** `archive/experimental/` 作为历史参考代码，同时明确：
- `src/` 主代码不得导入 `archive/`（通过检索/测试约束）。
- 在根 `README.md` 标注 `archive/` 为“仅历史参考”（见 ANE-0026）。

## 理由
- 避免删除历史代码/数据导致不可逆丢失。
- 通过“明确标注 + 不被主代码引用”的方式降低认知负担，同时保留回溯价值。

## 后续可选项（不在本批次执行）
- 若未来确认完全无用且需要收敛仓库体积：再考虑迁移到独立仓库或单独分支。
