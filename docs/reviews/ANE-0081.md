# ANE-0081 — core 自动索引线程（应移出 core）

## 结论
`src/core/project.py` 在 `create_project()` 与 `open_project()` 成功后都会调用 `_trigger_auto_indexing_async()`，该路径在 core 内部启动 Qt 线程执行“智能自动索引”逻辑，属于需要迁移到 TaskManager/IndexScheduler 的并发实现之一。

## 证据（定位）
- 调用点：
  - `src/core/project.py`：`create_project()` 内部在 emit `projectChanged` 后调用 `_trigger_auto_indexing_async()`（见 grep：`_trigger_auto_indexing_async` 出现在行 178 左右）
  - `src/core/project.py`：`open_project()` 内部在 emit `projectChanged` 后调用 `_trigger_auto_indexing_async()`（见 grep：`_trigger_auto_indexing_async` 出现在行 215 左右）
- 实现位置：
  - `src/core/project.py`：`def _trigger_auto_indexing_async(self):`（见 grep：定义在行 573 左右），内部使用 `QThread` + `sleep` 延迟并访问 `shared.ai_manager` 执行索引。

## 关联约束
该并发路径已在 `docs/architecture/tasks.md` 的“现存并发实现清单（待替换参考）”中纳入统一收敛计划：后续应通过 `IndexScheduler` 监听 `Shared.documentSaved` 并由 `TaskManager` 统一取消/去重/错误上报。
