# ANE-0124 Event-driven Indexing Contract

- Single source of truth:
  - `Shared.projectChanged` is emitted only by `Shared.current_project_path` setter.
  - `Shared.documentSaved` is emitted only by `ProjectManager.update_document()` after persistence.
- Event-driven indexing:
  - GUI listens to `Shared.projectChanged` and `Shared.documentSaved` to schedule indexing tasks.
  - UI should not directly schedule indexing on save; it must rely on the scheduler that listens to the shared signals.
- Deduping expectations:
  - At most one full project scan per `projectChanged` trigger (new trigger cancels the previous scan).
  - Per-document saves are debounced and coalesced by `document_id`.

Sub-issues implement the concrete wiring and enforcement; this note fixes the contract to avoid dual triggers.
