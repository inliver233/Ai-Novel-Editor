# ANE-0200 — Codex 数据库交互封装到 repository

目标：将 Codex 的数据库读写从 `CodexManager` 中抽离到独立 repository，便于后续把 CodexManager 迁移为纯 domain（无 Qt 依赖）并提供 Qt Adapter。

## 变更
- 新增 `src/core/codex_repository.py`：
  - 负责 Codex entries/references 的加载与保存
  - 负责引用访问统计与软删除的 DB 更新
- `src/core/codex_manager.py`：
  - 构造 `CodexRepository`，将 `_load_data/_save_data` 和增量 entry CRUD 以及 reference 更新落到 repository

## 说明
- 当前仍通过 `DatabaseManager` 实现具体 SQL；repository 作为 Codex 的窄接口，减少 `CodexManager` 直接触达数据库细节。
