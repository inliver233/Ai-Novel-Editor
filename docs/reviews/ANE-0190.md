# ANE-0190 — 触发位置（写死）

目标：把“项目切换触发链路”写死，避免实现期猜测/多处重复 emit 导致竞态。

## 写死的触发链路（Phase 1）
1) `ProjectManager.create_project/open_project` 成功后：只通过设置 `Shared.current_project_path = project_path` 触发项目切换信号。
2) `Shared.current_project_path` 的 setter 统一 `emit projectChanged(project_path)`。
3) 监听方（Phase 1）：`IndexScheduler` 监听 `Shared.projectChanged`，负责解析 per-project `vectors.db` 路径、必要时弹窗并切换 `shared.vector_store` / `shared.rag_service` 的工作模式。

## 代码落点
- `src/core/project.py`：设置 `self._shared.current_project_path = project_path`
- `src/core/shared.py`：`current_project_path` setter -> `projectChanged.emit(str(path))`
- `src/gui/services/index_scheduler.py`：`bind_shared()` 里连接 `projectChanged` 并处理切换策略
