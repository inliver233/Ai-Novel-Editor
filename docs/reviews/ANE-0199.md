# ANE-0199 — Codex 数据结构迁移到 domain

目标：将 `CodexEntry` / `CodexReference` / `CodexEntryType` / `ValidationResult` 等纯数据结构迁移到 domain 层，作为后续 “CodexManager 去 Qt 化（Domain + Repository + Qt Adapter）” 的基础。

## 变更
- 新增 `src/domain/codex_models.py`：承载 Codex 相关的数据结构（纯 Python，无 Qt 依赖）。
- `src/core/codex_manager.py` 改为从 `domain.codex_models` 导入上述类型，避免在 core 里定义/维护多份。

## 兼容性
- 仍保持 `core.codex_manager` 中的类型名可用（通过导入并在同名符号上暴露），不要求立刻改动所有调用方。
