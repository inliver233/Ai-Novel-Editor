# ANE-0302 安全修复说明：UI 保存时不再把 API key 明文写入 `config.json`

涉及路径：
- `src/core/config.py`：对 `ai.api_key` / `rag.api_key` 写入做拦截，改为写入安全存储，配置文件中始终写空字符串。
- `src/core/secure_key_manager.py`：本地加密文件后端（默认）。

## 行为变化

- UI/代码调用 `Config.set('ai'/'rag', 'api_key', <明文>)` 或 `Config.set_section('ai'/'rag', {..., api_key: <明文>})` 时：
  - 明文会被写入安全存储（key store）
  - `config.json` 中对应字段会被写成空字符串（不落盘明文）

## 自动化证据

- `tests/test_secure_storage_defaults.py` 覆盖：
  - `ai.api_key` 写入后：`config.json` 不含明文，安全存储可读回
  - `rag.api_key` 写入后：`config.json` 不含明文，安全存储可读回

## 手工验收建议（对齐 Issue Test_Method）

1) 打开应用 → 在 AI 配置 / RAG 配置中填写 API key → 保存  
2) 重启应用 → 触发一次 AI/RAG 调用确认 key 可用  
3) 检查 `config.json`：`ai.api_key` / `rag.api_key` 为空或不存在  
4) 检查安全存储文件存在且包含对应条目（Windows 默认：`%LOCALAPPDATA%/AI-Novel-Editor/secure/api_keys.json`）
