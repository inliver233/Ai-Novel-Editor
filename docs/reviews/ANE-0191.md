# ANE-0191 — create/open 仅通过 Shared.current_project_path 触发 projectChanged

## 结论
`ProjectManager.create_project()` / `open_project()` 成功后通过设置 `Shared.current_project_path` 触发 `projectChanged`，并已移除手动 emit，符合“仅通过 setter 触发”的约束。

## 证据
- `src/core/shared.py`：`current_project_path` setter 内部 `projectChanged.emit(str(path))`
- `src/core/project.py`：成功路径只设置 `self._shared.current_project_path = project_path`（不再手动 emit）
