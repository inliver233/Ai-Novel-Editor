# ANE-0082 — completion/AI 请求线程：AIWorkerThread(QThread)

## 结论
当前 AI completion / 多模态 / 工具调用请求在 `src/core/ai_qt_client.py` 通过 `AIWorkerThread(QThread)` 执行，并以 Qt signals 回传结果/错误/完成事件；该路径属于需要纳入 TaskManager 统一取消与错误上报的并发实现之一。

## 证据（定位）
- `src/core/ai_qt_client.py`：定义 `class AIWorkerThread(QThread)`（文件头部，约第 20 行起）
  - signals：`responseReceived`、`streamChunkReceived`、`errorOccurred`、`requestCompleted`、`toolCallStarted/Completed`
  - 取消：`cancel_request()` 通过 `_cancelled` 标记实现协作式取消（具体检查点在 run/请求执行流程中）

## 关联约束
该并发实现已在 `docs/architecture/tasks.md` 的“现存并发实现清单（待替换参考）”中纳入收敛计划：
- Phase 1：允许保留 `AIWorkerThread`，但取消与错误上报需走 TaskManager 统一通道
- Phase 2：再把 QThread 模型迁移到统一 runnable 模型
