# ANE-0275 Review — installed uses QStandardPaths

## Decision

- **installed（默认）**：当未启用 portable（`ANE_PORTABLE` / `portable.flag`）时，配置目录使用 `QStandardPaths.AppConfigLocation`，并追加 `ai-novel-editor/` 子目录。

## Evidence

- Implementation: `src/core/config.py` → `Config._get_config_dir()` 在 portable 未启用时走 `QStandardPaths.writableLocation(AppConfigLocation)`。

## Manual check (optional)

Run (does not require starting the full UI):

```powershell
py -3.11 -c "from PyQt6.QtCore import QStandardPaths; print(QStandardPaths.writableLocation(QStandardPaths.StandardLocation.AppConfigLocation))"
```
