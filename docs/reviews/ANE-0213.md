# ANE-0213 — 默认取舍（写死，避免执行者拍脑袋）

## 结论（默认取舍）
- 入口协调器：保留 `src/gui/editor/smart_completion_manager.py` 作为 completion/ghost 的单一协调入口。
- 默认 ghost 渲染：优先使用 `src/gui/editor/optimal_ghost_text.py`；仅在不可用时回退到 `deep_integrated_ghost_text.py`。
- 保留 inline：`src/gui/editor/inline_completion.py`（由协调器统一创建/管理，避免重复实例）。
- 保留 popup：`src/gui/editor/completion_widget.py`（由协调器统一创建/管理，避免重复实例）。
- deep 版本：`src/gui/editor/deep_integrated_ghost_text.py` 仅作为回退与回归对齐用途，后续逐步废弃。
- 同名冲突风险：`src/gui/ai/completion_widget.py` 与 `src/gui/editor/completion_widget.py` 同名，建议后续重命名以减少误导（本条仅记录默认取舍与风险，不在本 Issue 中强制重命名）。

## 代码落点（写死位置）
- `src/gui/editor/text_editor.py`：默认选择 `OptimalGhostText`，并显式允许回退到 deep（仅作为 fallback）。
- `src/gui/editor/smart_completion_manager.py`：统一持有 popup/inline 组件，并作为 Ghost Text 状态机的协调方（避免多套 widget 并存导致“残留 UI / 状态错乱”）。
