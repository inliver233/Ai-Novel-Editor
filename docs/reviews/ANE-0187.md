# ANE-0187 — Phase 1 强制走方案 A（per-project vectors.db）

Phase 1 约束：向量库必须按项目隔离存放，避免跨项目 embeddings 混用与检索泄露。

## 写死的行为
- 项目打开后，向量库路径解析为：`<project_path>/.rag/vectors.db`（目录不存在则创建）。
- `Shared.projectChanged(project_path)` 是触发切换的唯一事件源；监听方负责创建 per-project 向量库并绑定到 `shared`。
- legacy 全局库 `~/.ai-novel-editor/vector_store/vectors.db` 仅用于“检测/提示/迁移入口”，不作为检索数据源继续使用。

## 代码落点
- `src/core/vector_store_paths.py`：统一解析/创建 per-project vectors 路径。
- `src/gui/services/index_scheduler.py`：
  - 监听 `Shared.projectChanged`
  - 创建 `SQLiteVectorStore(<project>/.rag/vectors.db)` 并调用 `rag_service.set_vector_store(new_store)`
  - 若检测到 legacy 全局库存在且包含 embeddings：弹窗引导（重建/禁用/迁移）
- `src/main.py`：启动时不再创建/绑定 legacy 全局向量库，避免误用。
