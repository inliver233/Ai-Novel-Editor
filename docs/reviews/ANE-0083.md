# ANE-0083 — UI 保存后索引线程池（MainWindow 保存后异步索引）

## 结论
当前 UI 层在保存路径中包含多处“延迟/后台索引”逻辑（`QTimer.singleShot` + `QThreadPool/QRunnable`），属于需要统一收敛到 `IndexScheduler`/`TaskManager` 的并发实现之一。

## 证据（定位）
- `src/gui/main_window.py`：
  - `_on_save()`：保存成功后使用 `QTimer.singleShot(1000, ...)` 延迟调用 `_delayed_index_document(...)`（避免阻塞保存/UI）
  - `_delayed_index_document()`：内部定义 `IndexWorker(QRunnable)` 并通过 `QThreadPool.globalInstance().start(worker)` 在后台线程执行索引
  - `_on_document_saved_auto_index()`：监听“文档保存信号”后再次 `QTimer.singleShot(2000, ...)` 触发 `_delayed_index_document(...)`

## 关联约束
该路径已在 `docs/architecture/tasks.md` 的“现存并发实现清单（待替换参考）”中纳入收敛计划：
- RAG 索引应统一切到 `IndexScheduler` 监听 `Shared.documentSaved`
- 取消/去重/错误上报应通过 `TaskManager` 统一通道，避免 UI 保存路径双触发与竞态
