# ANE-0121 Epic 2.1 Evidence

- Core no longer imports/uses QThread for auto-indexing; indexing is handled in GUI via `IndexScheduler` + `TaskManager`.
- `Shared.current_project_path` is the single source for `projectChanged` emission; manual emits removed.
- `IndexScheduler` listens to `Shared.projectChanged`/`documentSaved`, switches per-project `vectors.db`, and schedules missing-doc scans with dedupe.
- UI no longer schedules indexing directly on save; indexing flows through `Shared.documentSaved`.
