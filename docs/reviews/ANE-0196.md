# ANE-0196 — rag_service 不存在时：只设置 vector_store，并在 UI 明确提示 “RAG 未启用”

目标：当 `shared.rag_service` 不存在（ImportError/禁用）时，项目切换仍能完成 vectors 路径解析与 `shared.vector_store` 注入，但不触发 RAG 检索/索引；同时 UI 在用户进入相关入口时明确提示 RAG 未启用。

## 行为约束
- `rag_service` 不存在时：
  - 仍创建/切换 per-project `SQLiteVectorStore(<project>/.rag/vectors.db)` 并设置 `shared.vector_store`
  - 不调用 `rag_service.set_vector_store(...)`
  - `IndexScheduler` 将 RAG 视为 disabled，跳过 `rag/*` 调度（避免后台反复失败）
- UI：当用户打开索引管理/批量索引入口时，弹窗提示 `RAG 未启用` 并引导打开配置对话框。

## 代码落点
- `src/gui/services/index_scheduler.py`：`_ensure_vector_store()` 在 `rag_service` 缺失时仅注入 `shared.vector_store`，并设置 `_rag_disabled=True`。
- `src/gui/main_window.py`：`_show_index_manager()` / `_show_batch_index_dialog()` 在 RAG 不可用时显示 `RAG 未启用` 提示。
