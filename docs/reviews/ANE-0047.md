# ANE-0047 — 普通保存不触发自动备份

## 结论
普通保存路径（`ProjectManager.save_project` → `DatabaseManager.save_project_data`）不会触发任何备份流程；备份仅在迁移/导入/删除/清空等危险操作路径中显式创建。

## 证据
- `src/core/database_manager.py` 的 `save_project_data` 仅做写入事务，无备份调用
- 备份仅在以下路径触发：迁移（`_migrate_database`）、导入（`create_pre_import_backup`）、删除（`create_pre_delete_backup`）、清空向量（`create_pre_vectors_clear_backup`）
